# GRC102 — Week 1 Practical Laboratory

**Information Security Governance in Action: GlobalHealth Connect (GHC) Executive Governance Simulation**

Course: GRC102 – Information Security Governance
Module: Module 1 – Principles of Information Security Governance

## Overview

This report responds to the Week 1 Practical Laboratory brief, acting as newly appointed Director of Information Security Governance at GlobalHealth Connect (GHC), a health-technology organisation addressing an ad-hoc security approach following rapid growth, two acquisitions, and a contained data-leakage near-miss.

## Contents

- **Task 1 — Governance Blueprint**: current-state gap assessment, governance organisational chart, and a RACI matrix across six governance activities.
- **Task 2 — Information Security Charter**: formal charter (purpose, scope, authority, roles, principles, reporting, review) plus a justification memo to the CFO.
- **Task 3 — Board Reporting and Security Metrics**: Board executive summary with an overall RAG posture rating, five selected metrics with six-month trend commentary, priority risks and recommendations.
- **Task 4 — Security Steering Committee**: Terms of Reference, a sample first-meeting agenda, and a briefing note to the CEO.
- **Task 5 — Governance Maturity Assessment**: current-state maturity ratings across six domains and a 12–18 month roadmap of priority initiatives.
